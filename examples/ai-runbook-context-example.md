# AI-RUNBOOK-CONTEXT: пример (синтетический)

> **Внимание:** это вымышленный пример для демонстрации формата. Не реальный сервер, не руководство к действию. Реальный runbook создаётся для конкретной конфигурации. Все данные (хостер, домен, IP, имена, версии) выдуманы.

**Назначение:** этот файл даёт AI-ассистенту полный контекст сервера для помощи с администрированием.

**Не содержит секретов** — UUID, ключи, токены в отдельном файле на сервере.

## 1. Общая информация

- **Тип:** VPS для личного VPN.
- **Хостер:** Hetzner (Германия), хостнейм vpn-node-01.
- **ОС:** Debian 12, 2 vCPU / 2 GB RAM / 20 GB SSD.
- **Домен:** через Cloudflare (ACME DNS-01, порт 80 закрыт).
- **Реальный IP:** <SERVER_IP>.
- **Снапшоты:** вручную в панели Hetzner перед рискованными операциями.
- **Проверено на:** Xray 25.x, nginx 1.22, Debian 12.

## 2. Состав сервисов

- **Xray** — VLESS-прокси. Один inbound WS на 8443, только loopback, снаружи — через nginx.
- **nginx** — TLS-фронтенд на 443. Терминирует сертификат, проксирует /ws на Xray:8443.
- **fail2ban** — защита SSH.
- **UFW** — файрвол. Открыто: 22/tcp, 443/tcp.
- **certbot.timer** — продление ACME-сертификата через DNS-01 (Cloudflare API).
- **logrotate.timer** — системные задачи.
- **vnstat** — счётчик трафика.

## 3. Транспорты для клиентов

Один транспорт:
- **VLESS + WebSocket + TLS** — работает во всех клиентах (v2rayNG, NekoBox, Happ). ~50 Mbps на мобильном интернете.

**Per-user идентификаторы:** у пользователя свой UUID в inbound. В логах видно email: <имя>.

## 5. Правила для AI-ассистента

- **Вопросы задавать по одному.** Задал — дождался ответа — задал следующий.
- **Команды давать по одной.** Мобильный SSH-клиент, heredoc тяжело копировать.
- **Секреты не выводить в чат.** Использовать cut -c1-8, ***.
- **После изменения конфига Xray** — xray -test перед systemctl restart xray.
- **После изменения nginx** — nginx -t перед systemctl reload nginx.
- **Перед рискованными операциями** — снапшот в Hetzner.
- **Не использовать UID** как имя переменной в bash.

## 8. Известные особенности и грабли

### 8.1. Архитектурные решения

- **Xray слушает только loopback.** Снаружи — через nginx. Это намеренно.
- **nginx зафиксирован** через apt-mark hold. При обновлении до 1.25+ синтаксис меняется.

### 8.2. Что НЕ надо делать

- **Не переводить nginx в disable.** После ребута не поднимется.
- **Не менять per-user UUID обратно на общий.** Потеряется идентификация.
- **Не публиковать /root/vpn-secrets/runbook-full.md** в чат или облако.

### 8.3. Особенности окружения

DNS на клиентах — только явный (1.1.1.1). Иначе запросы уйдут провайдеру напрямую.
